# Add OBSpamCheck to ob-labs

## Summary
Propose to add a new repository `OBSpamCheck` to the ob-labs organization.

## Repository Introduction
OBSpamCheck is a community spam detection tool for OceanBase, which is used to identify water posts, invalid comments and low-quality content in the ask.oceanbase.com community, and realize user behavior statistics and sorting capabilities.
