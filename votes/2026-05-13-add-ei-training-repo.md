# 申请创建 ei-training 项目

## 项目基本信息

项目名称：ei-training

项目目的：Kubernetes 原生的具身智能（Embodied AI）数据集管理平台，支持 LeRobot 机器人数据集的上传、VLM 标注解析、语义搜索与训练数据服务。利用 OceanBase 的原生 VECTOR 和 FULLTEXT 索引实现混合语义搜索，通过双状态机和多卷并行流水线将原始机器人数据高效转换为 GPU 就绪张量。


开源协议：Apache 2.0

> 建议采用 Apache 2.0，如果不采用 Apache 2.0 协议，请注明原因
